## 实验详情

### 实验一　线性回归及其变体算法实践

从最基础的线性回归出发，延伸至岭回归、Lasso 等正则化变体，理解偏差—方差权衡与特征选择思想。

### 实验二　支持向量机（SVM）分类与回归实验

掌握间隔最大化原理、核技巧，并分别完成分类与回归任务，体会 SVM 在不同场景下的表现。

### 实验三　集成学习初探 —— AdaBoost 与随机森林

对比 Boosting 与 Bagging 两大范式：AdaBoost 侧重自适应加权，随机森林侧重样本与特征双重随机。

### 实验四　集成学习进阶 —— GBDT 与 XGBoost 对比实验

在梯度提升框架下，比较 GBDT 与 XGBoost 的算法差异、工程优化与调参策略。

### 实验五　无监督学习 —— 经典聚类算法实验

实践 K-Means、层次聚类、DBSCAN 等经典算法，理解距离度量、簇结构与噪声处理。

### 实验六　神经网络基础 —— BP 神经网络实现与调参

从零理解前向传播与反向传播，动手实现 BP 网络并完成超参数调优，迈入深度学习门槛。

## 项目目标

1. **建立直觉**：通过代码与可视化，把公式变成可感知的模型行为。  
2. **掌握流程**：熟悉数据预处理 → 模型训练 → 评估 → 调参的完整流水线。  
3. **对比理解**：在同类算法之间做横向对比，明确各自适用边界。  
4. **独立实践**：每个实验均可独立运行、复现与扩展。
