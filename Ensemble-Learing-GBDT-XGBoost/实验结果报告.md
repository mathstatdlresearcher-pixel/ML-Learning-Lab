# Titanic 生存预测实验报告

本报告汇总探索性分析、预处理、特征工程，以及 **决策树 / 逻辑回归 / AdaBoost / 随机森林 / GBDT / XGBoost** 的网格搜索与评价指标。

复现命令：`python run.py`（代码按文件夹拆分，见 `titanic_ml/`）。

## 1. 为什么官方 test.csv 不能直接算 Precision / Recall / F1 / AUC

Kaggle 文件 `titanic-dataset/test.csv` **没有 `Survived` 列**（418 条，仅特征）。没有真实标签时，任何分类指标都无法计算，只能输出预测概率与 0/1。

因此采用如下划分（全部随机种子 `2023`，分层抽样）：

| 数据集 | 来源 | 样本数 | 用途 |
| --- | --- | ---: | --- |
| 训练集 | `train.csv` 的 80% 再按 80/20 切开后的训练部分 | 569 | 拟合 + 5 折网格搜索 |
| 验证集 | 上述 80% 中的 20% | 143 | 调参后对照、选主模型 |
| **带标签测试集** | `train.csv` 预先留出的 20% | 179 | **最终 Precision / Recall / F1 / AUC** |
| Kaggle 测试集 | `test.csv` | 418 | 无标签，只保存预测 |

也就是：先从 `train.csv` 划出 20% 作为**带标签测试集**（不参与训练与网格搜索），剩余 80% 再按 80%/20% 划分为训练集与验证集。

## 3. 预处理与特征工程

规则：缺失 >50% 删列；文字缺失用**训练集众数**；连续缺失用**拉格朗日插值**（邻域 k=5，Age 裁剪到 [0,80]）。分箱与哑变量边界只在训练集上估计。

实际填充记录：

- `Embarked`：{'type': 'mode', 'value': 'S'}
- `Age`：{'type': 'lagrange', 'k': 5}
- `Fare`：{'type': 'lagrange', 'k': 5}

哑变量列：`Sex, Embarked, Title, Pclass, AgeBin, FareBin, TicketGroup, FamilyBin, CabinDeck, SexPclass`

最终特征维数：**54**。列名见 `outputs/run_summary.json`。

## 4. 网格搜索最优参数

5 折 `StratifiedKFold`（`shuffle=True, random_state=2`），`refit=roc_auc`，同时记录 CV 上的 Precision / Recall / F1 / Accuracy。

- **DecisionTree**：`criterion`=gini, `max_depth`=5, `min_samples_leaf`=8, `min_samples_split`=2
- **LogisticRegression**：`clf__C`=0.1, `clf__class_weight`=None, `clf__penalty`=l1
- **AdaBoost**：`estimator__max_depth`=2, `learning_rate`=0.03, `n_estimators`=60
- **RandomForest**：`max_depth`=6, `n_estimators`=240
- **GBDT**：`learning_rate`=0.05, `max_depth`=2, `n_estimators`=80, `subsample`=1.0
- **XGBoost**：`colsample_bytree`=0.8, `learning_rate`=0.05, `max_depth`=3, `n_estimators`=80, `subsample`=0.8

完整靠前组合见 `outputs/gridsearch_top.csv`。

## 7. 方法对比要点

- **决策树**：可解释、网格含深度与叶节点；容易过拟合（训练 AUC 明显高于测试）。
- **逻辑回归**：线性基线，L1/L2 与 `C`、类别权重网格；特征已标准化。适合对照「非线性集成是否值得」。
- **AdaBoost**：加权弱分类器，Recall 往往较高。
- **随机森林**：袋装降低方差，验证/测试 AUC 通常稳定。
- **GBDT**：梯度提升，对表格式竞赛很强。
- **XGBoost**：二阶近似 + 列采样，需看训练/测试差距判断过拟合。
